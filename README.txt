MI DINERO PARA IPHONE

1. Sube toda esta carpeta a un hosting HTTPS (GitHub Pages, Netlify o Cloudflare Pages).
2. Abre la URL en Safari del iPhone.
3. Pulsa Compartir > Añadir a pantalla de inicio > Abrir como app.
4. Los datos se guardan en el dispositivo. Usa Exportar datos con frecuencia para crear copias de seguridad.
5. Para noticias, crea una API key en Finnhub e introdúcela en la pestaña Inversión.

Aviso: el análisis de titulares es orientativo y educativo; no es asesoramiento financiero.

V2: incluye pestaña Ahorro con ahorro, inversiones, ubicación/concepto, altas, retiradas, distribución e historial.
